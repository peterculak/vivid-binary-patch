# Complete lldb Debugging Session - Step by Step

This is the **actual, complete transcript** of our debugging session with detailed explanations of every step.

## Step 1: Launch Vivid in lldb

```bash
$ lldb /Applications/Vivid.app/Contents/MacOS/Vivid
(lldb) target create "/Applications/Vivid.app/Contents/MacOS/Vivid"
Current executable set to '/Applications/Vivid.app/Contents/MacOS/Vivid' (arm64).
```

**What this does:**
- Loads Vivid into the debugger
- Doesn't start the app yet - just prepares it
- Shows it's an ARM64 binary (Apple Silicon)

---

## Step 2: Set Breakpoint on boolForKey:

```lldb
(lldb) b -[NSUserDefaults boolForKey:]
Breakpoint 1: where = Foundation`-[NSUserDefaults(NSUserDefaults) boolForKey:], address = 0x0000000182824840
```

**What this does:**
- `b` = breakpoint
- `-[NSUserDefaults boolForKey:]` = Objective-C method that reads boolean values from UserDefaults
- This will stop **every time** any code reads a boolean from UserDefaults

**Why this works:**
- Vivid stores its license as `userHasValidLicense` in UserDefaults
- When it checks the license, it must call this function
- We'll catch it red-handed!

---

## Step 3: Add Condition to Filter

```lldb
(lldb) breakpoint modify 1 -c '(BOOL)[(NSString *)$arg3 isEqualToString:@"userHasValidLicense"]'
```

**What this does:**
- `breakpoint modify 1` = Modify breakpoint #1
- `-c` = Add a condition
- `$arg3` = The 3rd argument (the key name)
- Only stop if the key equals "userHasValidLicense"

**Why we need this:**
- Without this, the breakpoint would hit hundreds of times (for every UserDefaults read)
- With this, it only stops when checking the license key

**Parameter positions:**
- `$arg1` = `self` (the NSUserDefaults object)
- `$arg2` = `_cmd` (the selector/method name)
- `$arg3` = first parameter (the key string) ← This is what we check!

## Step 9: Understanding the Critical Code

Let's break down the important parts:

### Line 0x100043654: Call the Getter
```asm
0x100043654 <+52>:  bl     0x1000b7268    ; SwiftUI.AppStorage.wrappedValue.getter
```
**What this does:**
- `bl` = Branch with Link (function call)
- Calls SwiftUI's `@AppStorage` getter
- This is what reads `userHasValidLicense` from UserDefaults
- The result is stored on the stack

### Line 0x100043660: Load the Result
```asm
0x100043660 <+64>:  ldrb   w8, [sp, #0x8]
```
**What this does:**
- `ldrb` = Load Register Byte
- `w8` = Destination register (32-bit)
- `[sp, #0x8]` = Read from stack at offset +8
- **Loads the boolean license status into register w8**

### Line 0x100043664: THE LICENSE CHECK! 🎯
```asm
0x100043664 <+68>:  tbnz   w8, #0x0, 0x1000436d0 ; <+176>
```

**THIS IS IT!** This is the instruction we need to patch!

**Breaking it down:**
- `tbnz` = Test Bit and Branch if Not Zero
- `w8` = The register with the license status
- `#0x0` = Test bit 0 (the boolean value)
- `0x1000436d0` = Where to jump if licensed

**In plain English:**
"If the license is valid (w8 bit 0 is 1), jump to address 0x1000436d0 (the licensed features code). Otherwise, continue to the next line (restriction code)."

### What Happens Next

**If licensed (w8 = 1):**
- Jump to `0x1000436d0`
- Show all premium features
- No restrictions

**If unlicensed (w8 = 0):**
- Continue to line `0x100043668`
- Execute restriction code
- Show "activate license" messages

---

## Step 10: The Patch Strategy

We found the check at **address `0x100043664`**:
```asm
tbnz w8, #0x0, 0x1000436d0
```

**Our patch:**
Replace it with an **unconditional branch**:
```asm
b 0x1000436d0
```

**Result:**
- Always jump to the licensed code
- Never execute the restriction code
- License check is bypassed!

---

## Summary of What We Found

| Item | Value |
|------|-------|
| **Memory Address** | `0x100043664` |
| **Instruction** | `tbnz w8, #0x0, 0x1000436d0` |
| **Bytes** | `68 03 00 37` |
| **What it does** | Checks if licensed, jumps if true |
| **Our patch** | `b 0x1000436d0` (always jump) |
| **Patch bytes** | `1b 00 00 14` |

## Key Learnings

1. **Breakpoints** can catch specific function calls
2. **Conditions** filter breakpoints to only what we care about
3. **`finish`** lets a function complete and shows the caller
4. **`up`** moves up the call stack to find calling code
5. **`disassemble`** shows the actual machine code
6. **Conditional branches** can be made unconditional
7. **One instruction change** can unlock an entire app!

## Calculating the Offset

```
Memory address: 0x100043664
Base address:   0x100000000
Initial offset: 0x100043664 - 0x100000000 = 0x43664
```

But this is wrong! We need to search for the bytes in the file because it's a universal binary.

## Finding the Actual Offset

```python
with open('/Applications/Vivid.app/Contents/MacOS/Vivid', 'rb') as f:
    data = f.read()
    offset = data.find(b'\x68\x03\x00\x37')
    print(f"Found at offset: 0x{offset:x}")
```

Output:
```
Found at offset: 0x197664
```

**This is the correct file offset!**
